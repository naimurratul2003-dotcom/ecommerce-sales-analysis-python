# E-Commerce Sales Analytics - 5000 Orders Analysis

An end-to-end data analysis project on 5000 e-commerce transactions to uncover revenue trends, customer behavior, and product performance.

### 📊 Dataset
- **Source:** E-commerce Sales Analytics Dataset (5000 Orders)
- **Period:** Jan 2024 - Dec 2024
- **Key Columns:** Order Date, Product Category, Payment Method, Revenue, Profit, Customer Rating, Delivery Days, Customer Segment

### 🛠️ Tools & Libraries Used
- Python
- Pandas & NumPy - Data Cleaning & Manipulation
- Matplotlib & Seaborn - Data Visualization
- Jupyter Notebook

### 🔍 Analysis Performed
1.  Data Cleaning & Handling Missing Values
2.  Monthly Revenue & Profit Trend Analysis
3.  Product Category Performance
4.  Payment Method & Customer Segment Analysis
5.  Delivery Time vs Customer Rating Correlation
6.  RFM-style Top Customers Identification

### 💡 Key Business Insights
1.  **Top Category:** Electronics generated the highest revenue ($541,689).
2.  **Payment:** Card is the most preferred method (45.4% of orders).
3.  **Peak Season:** May was the highest revenue month with $479,586.
4.  **Customer Satisfaction:** Delivery time has almost zero correlation with Rating (r = -0.017), meaning faster delivery doesn't guarantee higher rating.
5.  **Loyal Customers:** Top 10 customers contributed 8% of total revenue.
6.  **Customer Base:** 88% are Returning Customers.

### 📁 Files in this Repository
- `ecommerce_sales_analysis.ipynb` - Complete analysis with code & visualizations
- `ecommerce_sales_analytics_5000.csv` - Raw dataset
- `README.md` - Project documentation
